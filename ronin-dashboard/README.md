# Ronin Dashboard

摄影师 Ronin 的消息管理看板。

## 功能特性

- 实时消息通知
- 消息状态管理（新消息/待处理/已完成）
- 按项目类型筛选
- 搜索功能
- 邮件快速回复
- 统计面板

## 技术栈

- HTML5 / CSS3
- LocalStorage 数据存储
- Lucide 图标

## 部署

部署到 GitHub Pages：

1. 创建 GitHub 仓库 `ronin-dashboard`
2. 上传 `index.html` 到仓库
3. 启用 GitHub Pages（Settings > Pages > Source: main branch）
4. 访问 `https://ronineymessjr-sudo.github.io/ronin-dashboard/`

## 数据来源

消息数据来自作品集网站的联系表单，通过 LocalStorage 共享。
