# Ronin Photography Portfolio

摄影师 Ronin 的个人作品集网站。

## 功能特性

- 响应式设计，支持移动端和桌面端
- 作品画廊展示，支持分类筛选
- 客户评价轮播
- 联系表单（集成消息看板）
- 实时作品统计
- 消息看板入口

## 技术栈

- HTML5 / CSS3
- GSAP 动画库
- Lucide 图标
- LocalStorage 数据存储

## 部署

部署到 GitHub Pages：

1. 创建 GitHub 仓库 `ronin-portfolio`
2. 上传 `index.html` 到仓库
3. 启用 GitHub Pages（Settings > Pages > Source: main branch）
4. 访问 `https://ronineymessjr-sudo.github.io/ronin-portfolio/`
